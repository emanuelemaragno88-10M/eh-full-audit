How to test the ECOM HOUSE Audit Tool

A guided walkthrough for Shopify App Store reviewers and internal QA.

Installation

  1. From the Partner Dashboard, install the app on a Shopify development store.
  2. Shopify Admin opens the app embedded in an iframe at /admin/apps/eh-full-audit.
  3. The app initializes via App Bridge and authenticates every backend call with a session token (Authorization: Bearer <jwt>) verified server-side using HS256 against SHOPIFY_API_SECRET.

What to test

  1. Dashboard — confirm the welcome screen, hero, and CTA buttons render.
  2. Connect Meta — review the read-only Meta OAuth flow. (Mock audit data is shown without an actual Meta account, so the full UI is reviewable without connecting Meta.)
  3. Audit Report — verify the A–F gauge renders, the four category cards show with status indicators, and the underlying API call is authenticated via session token.
  4. Action Items — confirm the prioritized recommendations list (High/Medium/Low badges, sorted).

What this app does

Generates a performance audit of a Shopify store and (optionally) a connected Meta Ads account. Scores four categories — Store Performance, Ad Creative Health, Funnel Optimization, Retention Strategy — and surfaces a prioritized action list.

Data access

  • read_products, read_orders, read_customers — used to compute store performance and retention metrics.
  • Read-only Meta Ads access via Facebook OAuth (optional, opt-in via the Connect Meta page).

GDPR compliance webhooks

  • POST /api/webhooks/customers-data-request
  • POST /api/webhooks/customers-redact
  • POST /api/webhooks/shop-redact

All three verify the X-Shopify-Hmac-Sha256 header using crypto.timingSafeEqual and respond 200 on valid HMAC, 401 on invalid.

Embedded rendering

Responses set Content-Security-Policy: frame-ancestors https://*.myshopify.com https://admin.shopify.com so the app renders inside the Shopify Admin iframe.
